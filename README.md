# Restaurant Website

A responsive and user-friendly restaurant website designed to provide information about the restaurant, showcase the food menu, and give users an attractive online experience.

## Features

- 🏠 Home page
- 🍔 Food menu section
- 📖 About the restaurant
- 📞 Contact section
- 📱 Responsive design
- 🎨 Attractive and user-friendly interface
- 🖼️ Food images and restaurant details

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- Mysql

## Project Purpose

The main purpose of this project is to create a simple and attractive online platform for a restaurant where users can explore the restaurant, view available food items, and find contact information.
